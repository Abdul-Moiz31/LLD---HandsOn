# Promisify Utilities

**Difficulty:** Easy

## Problem Statement

Implement utilities for converting callback-based APIs to Promise-based.

## Requirements

1. `promisify(fn)` - Convert callback function to Promise
2. `promisifyAll(obj)` - Promisify all methods on object
3. `callbackify(asyncFn)` - Convert async function to callback style
4. `delay(ms)` - Promise-based delay

## Function Signatures

```javascript
function promisify(fn) {}
function promisifyAll(obj) {}
function callbackify(asyncFn) {}
function delay(ms) {}
```

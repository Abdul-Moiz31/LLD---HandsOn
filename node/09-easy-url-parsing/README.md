# URL Parsing

**Difficulty:** Easy

## Problem Statement

Implement URL parsing and query string utilities.

## Requirements

1. `parseURL(urlString)` - Parse URL into components
2. `parseQueryString(qs)` - Parse query string to object
3. `buildQueryString(params)` - Build query string from object
4. `buildURL(base, path, params)` - Build complete URL

## Function Signatures

```javascript
function parseURL(urlString) {}
function parseQueryString(qs) {}
function buildQueryString(params) {}
function buildURL(base, path, params) {}
```

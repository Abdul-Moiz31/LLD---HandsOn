# CRUD REST API

**Difficulty:** Medium

## Problem Statement

Implement a complete CRUD REST API handler without frameworks.

## Requirements

1. Handle GET, POST, PUT, DELETE for resources
2. In-memory data store
3. Input validation
4. Proper HTTP status codes
5. JSON request/response handling

  // Return handler that manages /resourceName endpoints
